有効なユーザーの名前だけを取り出す

3人のユーザーから、active が true の人だけを残し、name だけを取り出します。下の4つは、同じ処理を言語ごとに書いたものです。

TypeScript

users はユーザーの配列です。

const names = users
  .filter(user => user.active)
  .map(user => user.name);

filter が選び、map が名前に置き換えます。

Ruby

users はユーザーの配列です。

names = users
  .select { |user| user[:active] }
  .map { |user| user[:name] }

select が選び、map が名前に置き換えます。

Python

users はユーザーのリストです。

names = [user["name"] for user in users if user["active"]]

if で選び、先頭の user["name"] を集めます。

SQL

users は表です。並び順を保つため id を使います。

SELECT name
FROM users
WHERE active = TRUE
ORDER BY id;

WHERE が選び、SELECT name が名前の列だけを返します。

型・関数・値まで含めた例

User は1人分のデータの形です。名前を取り出す処理を activeNames という関数にまとめています。

type User = { id: number; name: string; active: boolean };

function activeNames(users: User[]): string[] {
  // 有効な人を選んで、名前だけを取り出す
  return users
    .filter(user => user.active)
    .map(user => user.name);
}

const names = activeNames([
  { id: 1, name: "アキ", active: true },
  { id: 2, name: "ボブ", active: false },
  { id: 3, name: "メイ", active: true },
]);

結果はすべて ["アキ", "メイ"]。SQLでは、同じ2つの名前が結果の行として並びます。
