== 作業上の注意

* このリポジトリは PR を作らず、main に直接 commit・push する。commit はユーザーに確認してから行う。ユーザーは `/commit-push` で実行している。
* `git push` は、サンドボックスが `~/.ssh` の読み取りを禁止しているため、SSH 認証で失敗する。push は3回（`96810f9`、`e0afa45`、`92e47c2`）とも `dangerouslyDisableSandbox` で実行した。
* リポジトリ直下の未追跡の `.bashrc`、`.zshrc`、`.gitconfig`、`.mcp.json`、`.idea`、`.vscode` など11件は、0B のキャラクタ特殊ファイルで、サンドボックスの痕跡とみられる。`.claude/` もサンドボックスなどの状態ファイル。いずれも commit に含めない。
* これまでの commit では `git add -A` を使わず、変更したパスだけを stage した。`commit-push` スキルは `git add -A` と書いているが、上のファイルがある状態での挙動は確かめていない。
* 実行中の Claude Code セッションは、`/nix/store/...agent-skills-source-...` からスキルを読む。スキルの修正は、再ビルド後に始めたセッションから効く。
