# マージコンフリクトの解消

Codex と Claude Code のどちらでも、実行環境で利用できるシェルおよびファイル操作ツールを使って、次の手順を進める。

1. **merge / rebase の現在の状態を確認する。** Git の履歴と、コンフリクトしているファイルを確認する。

2. **各コンフリクトの一次情報を調べる。** それぞれの変更理由と本来の意図を深く理解する。commit メッセージを読み、PR と元の issue / ticket を確認する。

3. **各 hunk のコンフリクトを解消する。** 可能な限り双方の意図を保つ。両立できない場合は、merge の明示された目的に合う方を採用し、トレードオフを記録する。新しい振る舞いを勝手に追加してはならない。必ずコンフリクトを解消し、`--abort` は実行しない。

4. プロジェクトの**自動チェック**を調べて実行する。通常は typecheck、test、format の順に実行する。merge によって壊れた箇所があれば修正する。

5. **merge / rebase を完了させる。** すべてをステージして commit する。rebase の場合は、すべての commit の rebase が完了するまで処理を続ける。
