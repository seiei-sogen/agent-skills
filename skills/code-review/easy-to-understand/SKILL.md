# Easy To Understand

対象を馬鹿にもわかるようにわかりやすく、易しく説明する。
対象を、予備知識がない人でも内容と理由を理解できるようにもすることも当然含む。

## 説明する対象

- 引数がある場合は、その引数（fileなど）を対象にする。
- ない場合は直前のやりとりなど

## 出力

説明の内容と図を組み立てたら、`create-html` スキルを呼び出してHTMLを生成する。
スキル呼び出し機能がない場合は、利用可能なスキル一覧から `create-html` のSKILL.mdを開いて手順を実行する。このリポジトリでは [create-html](../../develop-flow/create-html/SKILL.md) を使う。

出力先には接頭辞 `easy-` で始まるHTMLファイル名を渡す。
コードの言語も渡し、`create-html` による細かなシンタックスハイライトと表示確認まで行う。
