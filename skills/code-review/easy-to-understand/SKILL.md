# Easy To Understand

対象を馬鹿にもわかるようにわかりやすく、易しく説明する。
図とかも取り入れる。
対象を、予備知識がない人でも内容と理由を理解できるようにもすることも当然含む。

## 説明する対象

- 引数がある場合は、その引数（fileなど）を対象にする。
- ない場合は直前のやりとりなど

## 文の要素を省略しない

HTMLの解説文は、読み手が前後の文を読まなくても「誰が・何を・どうした」が分かるように書く。
日本語は主語や目的語を省略しやすく、省略した文は読み手によって解釈が分かれるためである。

### ルール
1. 述語（動詞・形容詞・名詞＋だ）ごとに、その述語が必要とする要素をすべて書く。
    - 必要な要素は述語によって決まる。「届く」なら「何が・誰に」、「送る」なら「誰が・何を・誰に」、「AはBだ」なら「何が・何だ」。
    - 自動詞に目的語を足すなど、述語が必要としない要素を無理に補わない。
2. 文末の述語だけでなく、従属節（「〜したら」「〜ので」）、連体修飾節、受け身、動作を表す名詞（「確認」「削除」「対応」など）にもルール1を適用する。
    - 受け身の文は、誰がその動作をするのかを書くか、能動文に直す。

## 出力

説明の内容と図を組み立てたら、`create-html` スキルを呼び出してHTMLを生成する。
スキル呼び出し機能がない場合は、利用可能なスキル一覧から `create-html` のSKILL.mdを開いて手順を実行する。このリポジトリでは [create-html](../../develop-flow/create-html/SKILL.md) を使う。

出力先には接頭辞 `easy-` で始まるHTMLファイル名を渡す。
コードの言語も渡し、`create-html` による細かなシンタックスハイライトと表示確認まで行う。
