# 概要

`origin/develop` を現在のブランチにマージして、GitHub の PR で発生している競合を解消する。

## 手順

### 1. 対象ブランチと作業ツリーを確認する

```sh
git branch --show-current
git status --short
```

現在のブランチが作業対象であることを確認する。
`git branch --show-current` の出力が空（detached HEAD）、または作業対象と異なる場合は、処理を止めてユーザーに確認する。
`git status --short` に出力がある場合は、既存変更を `stash`、破棄、コミットせず、処理方法をユーザーに確認する。

### 2. フェッチし、`zdiff3` 形式でマージする

```sh
git fetch origin develop
```

フェッチに失敗した場合は処理を止め、古い `origin/develop` を使ってマージしない。
フェッチに成功した場合だけ、次を実行する。

```sh
git -c merge.conflictstyle=zdiff3 merge origin/develop
```

`zdiff3` は、競合マーカーにマージベースを表示しつつ、不要な重複を減らす。

- 競合なしでマージできた場合は、明示的な再生成指示があれば「生成ファイル」に従い、その後、手順5へ進む。
- マージコマンドが失敗した場合は、次のコマンドで未解消ファイルを確認する。

  ```sh
  git diff --name-only --diff-filter=U
  ```

  出力がある場合は、そのファイル一覧を記録して手順3へ進む。
  出力がない場合は競合として扱わず、処理を止めてエラーを報告する。

### 3. 競合を未解消のままコミットする

マージで競合が発生した場合は、**先に競合を解消せず、競合マーカーをそのままコミットする**。
これにより、解消前の競合状態が、解消内容とは別の専用コミットに記録される。

```sh
git add -A
git commit -m "merge origin/develop (conflicts unresolved)"
```

### 4. 競合を解消する

1. 手順2で記録した各ファイルを読み、競合の両側とマージベースを理解する。
2. 生成ファイル以外のファイルでは、競合マーカーを削除し、意図に合う内容へ統合する。
3. ゴールデンファイルや生成ファイルでは、後述の「生成ファイル」に従って再生成する。
4. 記録したすべてのファイルから競合マーカーがなくなり、内容が意図どおりであることを確認する。
5. `git status --short` で変更を確認し、想定外のファイルが含まれていないことを確かめる。
6. 解消結果をステージし、コミットする。

```sh
git add -A
git commit -m "resolve merge conflicts"
```

未解消状態と解消結果の2つのコミットを `squash` して1つにまとめてはならない。
いずれかのコミットがフックなどで失敗した場合は、`--no-verify` で回避せず、原因を報告してユーザーに確認する。

### 5. 簡易確認を実行する

```sh
mise run test
```

CI では clippy とフォーマットが適用されるため、ここではこの簡易確認で十分である。
テストが失敗した場合は同期完了とせず、原因を報告する。
テスト後に作業ツリーを確認する。

```sh
git status --short
```

出力がある場合は内容を確認し、生成結果を黙って破棄しない。
テストが成功し、作業ツリーに未処理の変更がなければ完了とする。

## 生成ファイル

- **ゴールデンファイルまたは生成ファイルで競合が発生した場合は、必ず再生成してコミットする。**
  リポジトリ既存のジェネレーターを再実行し、出力をコミットする。
  競合マーカーを手作業で解消しない。
  競合したファイルをスキップしたり、`on-task-done` や CI に先送りしたりしない。
- **競合がない場合は、タスクの明示的な指示に従って再生成の要否を判断する。**
  再生成が常に必要とは限らない。
  「常に再生成する」「CI が処理する」といった一般的な方針を、依頼内容より優先してはならない。
- **生成結果を黙って破棄してはならない。**
  作業ツリーをクリーンにしたり、フックの警告を消したりする目的で `git restore` を実行しない。
  生成結果はコミットするか、ユーザーに処理方法を確認する。
