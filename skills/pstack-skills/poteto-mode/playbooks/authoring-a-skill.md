### Authoring or modifying a skill

**スキルの声（voice）の責任は自分にある。**

1. **plugin-dev:skill-development** スキル（SKILL.md ファイルを執筆するための Claude Code のスキル）を使う。
2. スキルをバリデーションする。frontmatter に `name` と `description` があること、参照しているファイルが存在すること、スキル間リンクが解決できること。
3. 構造的なものならテストケースを書く。主観的なものなら省く。
4. **Opening a PR** を実行する。

迷ったら削除する。判断を変える文章だけを残す。やるべきことを伝え、理由は省く。理由がないと規則が分かりにくい場合だけ説明する。トーンをスコープに合わせる。**encode-lessons-in-structure** 原則スキルに従い、構造的な情報源（型、README、設定）を指し示す。他のスキルへはパスで委任する。言い直さない。繰り返し遭遇するのに捕捉されていないワークフローがあれば、新しいスキルを提案する。

**返答:** スキルの要約、主要な設計判断、バリデーションの注記。
