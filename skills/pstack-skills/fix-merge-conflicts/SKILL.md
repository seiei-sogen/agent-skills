# マージコンフリクトを直す

## トリガー

ブランチに未解消のマージコンフリクトがあり、ビルド可能な状態への確実な経路が必要なとき。

## ワークフロー

1. git status とコンフリクトマーカーから、コンフリクトしているファイルをすべて検出する。
2. 各コンフリクトを、最小で正しさ優先の編集で解消する。
3. 安全なら両側を保持することを優先する。そうでなければ、コンパイルが通り公開された動作を安定に保つ側を選ぶ。
4. ロックファイルは手で編集せず、パッケージマネージャのツールで再生成する。
5. コンパイル、リント、関連するテストを実行する。
6. 解消したファイルをステージし、主要な判断を要約する。

## ガードレール

- 変更は最小で読みやすく保つ。
- どのファイルにもコンフリクトマーカーを残さない。
- コンフリクトの解消中に広範なリファクタを避ける。
- コンフリクトの解消中に push やタグ付けをしない。

## 出力

- 解消したファイル
- 注目すべき解消の選択
- ビルド/テストの結果
