# Redesign From First Principles

変更を統合するとき、既存の設計に後付けで取り付けない。その要件が最初からあったかのように再設計する。

- 影響を受けるファイルをすべて読み、現在の設計を理解する
- 問う。「この新しい要件を持ってゼロから書くなら、何を作るか」
- 変更をすべての参照に波及させる。型、ドキュメント、例、根拠説明のセクション
- 再設計の全体を考え、それから段階的に届ける

これが、既存の設計に変更を統合するときにオプション価値（option value）を保つ方法である。
