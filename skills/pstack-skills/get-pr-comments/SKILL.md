# PR のコメントを取得する

## トリガー

アクティブなプルリクエストへのフィードバックについて、簡潔で対処可能な要約が必要なとき。

## ワークフロー

1. 現在のブランチのアクティブな PR を特定する。
2. レビューコメントとディスカッションのコメントを取得する。
3. フィードバックを重大度と対処可能性でグループ化する。
4. 簡潔なアクションリストを返す。

## 出力

- グループ化したフィードバックの要約
- 優先度順に並べたアクションリスト
- まだ明確化が必要な未解決の質問
