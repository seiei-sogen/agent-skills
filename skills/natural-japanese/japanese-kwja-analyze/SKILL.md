# KWJA でファイルを解析する

## 実行と出力

第1引数を解析対象の UTF-8 テキストファイルのパスとして扱う。
このスキルのディレクトリを基準に [scripts/analyze.sh](scripts/analyze.sh) を実行する。
別の作業ディレクトリから呼ぶ場合は、スクリプトと入力ファイルの絶対パスを渡す。

```bash
bash "<このスキルのディレクトリ>/scripts/analyze.sh" "<入力ファイルの絶対パス>"
```

スクリプトは KWJA の `typo,char,seq2seq,word` を実行する。
出力先は同じ階層の `<入力ファイル名>.kwja.txt`。たとえば `article.txt` なら `article.txt.kwja.txt` になる。
解析結果は KNP 形式で保存し、標準出力には保存先のパスを返す。
既存の出力ファイルは KWJA が成功した場合だけ置き換える。

## 解析結果の読み方

次の11種類の処理を実行した最終結果を、一つの KNP ファイルとして保存する。

| 処理 | 結果の読み取り |
| --- | --- |
| タイポ修正・単語正規化 | 修正・正規化後の形態素の表記や基本形。入力テキストと照合する |
| 分かち書き・形態素解析 | 形態素行の区切り、表記、読み、基本形、品詞、活用情報 |
| 固有表現認識 | `NE` 素性 |
| 言語素性付与 | 形態素・基本句などに付いた素性タグ |
| 係り受け解析 | 文節行 `*` と基本句行 `+` の係り先と関係 |
| 述語項構造解析・橋渡し照応解析・共参照解析 | `rel` タグの関係種別と参照先。関係種別を混同しない |
| 談話関係解析 | `談話関係` 素性と参照先 |

ファイルは11個の見出しに分かれたレポートや修正履歴ではない。
該当する固有表現や関係がなければ、そのタグは出力されない。タグの欠落を LLM で補わない。
参照先は文 ID と基本句などの位置を使って追い、文をまたぐ照応も読む。
タイポ修正・正規化によって入力と解析表記が異なるため、入力ファイルも比較用に残す。

## 他のスキルへ渡す場合

呼び出し元へ入力ファイルと解析ファイルの両方のパスを渡す。
原文と書き換え候補を比較する場合は、それぞれ別名の入力ファイルを使い、両方の解析結果を残す。
呼び出し元は同じディレクトリに対応表や分析メモなどの作業ファイルを作ってよい。
KNP ファイルはそのまま残し、作業ファイルの解釈や修復案を KWJA の出力と区別する。

## 完了条件

コマンドが成功し、解析ファイルに対象テキストに対応する形態素行、基本句・文節行、文末の `EOS` があることを確認する。
空のファイルや `EOD` だけの出力を解析完了としない。
出力内容を確認してから保存先を伝える。
KWJA が失敗した場合は原因を報告し、LLM による解析で代行しない。
